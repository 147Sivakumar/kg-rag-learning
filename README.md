# Knowledge Graph RAG (KG-RAG) Learning Project

A beginner-friendly Python project that combines **Knowledge Graphs** and **Retrieval-Augmented Generation (RAG)** to answer questions using facts stored in a Neo4j graph database and responses generated by an OpenAI language model.

## Project Overview

This project demonstrates how to:

- Load information from multiple text documents.
- Extract entities and relationships from text.
- Store a knowledge graph in Neo4j AuraDB.
- Retrieve relevant graph facts using Cypher queries.
- Generate natural-language answers using an OpenAI language model.
- Visualize the knowledge graph using NetworkX and Matplotlib.

## Features

- Multiple document loading
- Entity extraction
- Relationship extraction
- Neo4j graph database integration
- Graph-based fact retrieval
- LLM-powered question answering
- Knowledge graph visualization
- Interactive command-line interface

## Prerequisites

Before running the project, install:

- Python 3.10 or later
- A Neo4j AuraDB database
- An OpenAI API key
- Git (for uploading the project to GitHub)

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/kg-rag-learning.git
cd kg-rag-learning
```

Replace `YOUR_USERNAME` with your GitHub username.

### 2. Create a virtual environment

**Windows:**

```cmd
python -m venv venv
venv\Scripts\activate
```

### 3. Install dependencies

```cmd
pip install openai langchain-openai neo4j networkx matplotlib
```

Install any additional packages imported by your scripts.

If a `requirements.txt` file is available, use:

```cmd
pip install -r requirements.txt
```

## Environment Configuration

Configure the following environment variables before running the scripts:

```text
OPENAI_API_KEY=your_openai_api_key
NEO4J_URI=your_neo4j_connection_uri
NEO4J_USERNAME=neo4j
NEO4J_PASSWORD=your_neo4j_password
```

Set these variables in your local environment or load them from a `.env` file if your code supports it.

**Security:** Never commit API keys, passwords, or other secrets to GitHub. Keep `.env` out of version control.

## Running the Project

Run each script from the project directory in the order appropriate for your setup.

### Step 1: Load multiple documents

```cmd
python step1_multiple_documents.py
```

Loads the sample text documents from the `docs` directory.

### Step 2: Extract entities

```cmd
python step2_entity_extraction.py
```

Extracts entities such as people, companies, industries, and products.

For LLM-based entity extraction, run:

```cmd
python step2_llm_entity_extraction.py
```

### Step 3: Extract relationships

```cmd
python step3_relationship_extraction.py
```

Identifies relationships between extracted entities.

### Step 4: Test the Neo4j connection

```cmd
python step4_test_neo4j.py
```

Checks the connection to the Neo4j database.

### Step 5: Store the graph

```cmd
python step5_store_graph.py
```

Stores entities and relationships in Neo4j.

### Step 6: Retrieve graph facts

```cmd
python step6_graph_retrieval.py
```

Retrieves facts from the knowledge graph.

### Step 7: Ask questions

```cmd
python step7_graph_question_answering.py
```

Enter a question when prompted.

Example questions:

```text
Where does John work?
What does OpenAI develop?
Who works for Microsoft?
Which industry does John work in?
Which industry does John's company operate in?
```

### Step 8: Visualize the knowledge graph

```cmd
python step8_visualize_graph.py
```

Creates a visual representation of the graph and saves it as `knowledge_graph.png`.
